# 💳 Digital Wallet System

A console-based **Digital Wallet System** built in Kotlin to practice Object-Oriented Programming Concepts and application logic.

## Features

- Create and manage digital wallets
- Deposit money
- Withdraw money
- Check wallet balance
- Display wallet details
- Maintain transaction history
- Different rules for Personal and Business wallets
- Input validation

## Concepts Practiced
- Classes & Objects
- Constructors
- Abstract Classes
- Abstract Methods
- Inheritance
- Method Overriding
- Polymorphism
- Encapsulation
- `super` keyword
- Functions
- `when` expressions
- Loops
- Mutable Lists
- Input Handling
- Validation
- Basic application logic
