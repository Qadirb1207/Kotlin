# 💳 Digital Wallet System

A console-based **Digital Wallet System** built in Kotlin to practice Object-Oriented Programming Concepts and application logic.

## Features

- Create and manage digital wallets
- Deposit money
- Withdraw money
- Check wallet balance
- Display wallet details
- Maintain transaction history
- Different rules for Personal and Business wallets
- Input validation

## Concepts Practiced
- Classes & Objects
- Constructors
- Abstract Classes
- Abstract Methods
- Inheritance
- Method Overriding
- Polymorphism
- Encapsulation
- `super` keyword
- Functions
- `when` expressions
- Loops
- Mutable Lists
- Input Handling
- Validation
- Basic application logic


## Wallet Types

### Personal Wallet

- Has a daily spending limit.
- Deposits do not count towards the spending limit.

### Business Wallet

- Has a higher daily spending limit.
- Follows almost same transaction rules as the Personal Wallet.

## Transaction History

Successful transaction are stored using a Kotlin `MutableList`.

Example:

Rs. 500 deposited into your account!
Rs. 300 withdrew from your account!
